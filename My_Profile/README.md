# Jyotirmoy Chakraborty — Academic Research Portfolio

Public static website for PhD supervisors, researchers, and collaborators.

## Publishing on GitHub Pages

1. Create a **public** repository under `Joy-chakraborty-23`, with the exact name `Joy-chakraborty-23.github.io`.
2. Upload **all the files and folders in this ZIP** into the root of that repository (not the enclosing extracted folder).
3. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
4. Wait for publishing to complete, then open `https://joy-chakraborty-23.github.io/`.

This ZIP includes ready-to-use, absolute canonical and social-sharing URLs for that exact domain. If you publish to another domain instead, regenerate the SEO metadata first.

Do not upload the original unredacted CV, private report, or confidential project data to your public repository.
